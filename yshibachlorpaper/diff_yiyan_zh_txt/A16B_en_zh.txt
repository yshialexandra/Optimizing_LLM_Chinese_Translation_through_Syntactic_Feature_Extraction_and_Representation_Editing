在 Windows XP 时代发布的产品依赖于糟糕的、基于笔式输入的数据输入，即使是运行 Windows 7 的现代触摸型平板电脑也表现不佳。
事实上，微软有着不堪的平板电脑历史，公众很难忘记。
今年 11 月，Forrester 公司发布的一项研究显示，消费者对基于 Windows 的平板电脑的兴趣明显下降。
2011 年初，有 46% 的潜在平板电脑用户希望拥有一台 Windows 设备。
到了第三季度，这一数字下降到 25%。
福斯特公司的报告称，“Windows 8 还没有进入平板电脑买家的意识。”
这实在是可惜，因为 Gadget Lab 已经看到过 Windows 8 平板电脑的使用情况，这让我们意识到 Windows 8 平板电脑的实用性（甚至有趣）。
当然，微软只是展示了一个基础设计，但我们看到的内容很令人激动，我们真的很期待最终发布的产品。
Windows 8 从一开始就是为了在传统计算机（台式机和笔记本电脑）和触摸屏平板电脑上运行而开发的。
操作系统可以在 ARM 或 x86 处理器上运行，但专门为 x86 桌面环境编写的应用程序将无法在基于 ARM 的移动设备上运行。
这是一个可怕的缺陷吗？没有，根据我们所见，不是。
Windows 8 平板电脑将运行 Windows Phone 上的更新版 Metro UI，UI 显然可以很好地转移到较大的触摸屏上。
您将获得与 Windows 手机上的相同的有趣、友好和动画化“Live Tile”主屏幕，但是（理论上）拥有更强大的处理能力，可以驱动更强大的应用程序。
Windows 8 将于 2 月份进入测试版，预计将在 2012 年 6 月发布完整版软件。
我们迄今所看到的一切都表明，微软花了很多时间来开发一个平台，该平台可以在平板电脑上取得成功，同时也不会忽视公司的 PC 根基。
还是个怀疑者吗？你应该是。
Windows 平板电脑的热销早已不是第一次了。
但请考虑这四个原因，这些原因可能会让人们对微软即将进军平板电脑市场感到惊讶，最终证明微软的举措是成功的。
微软有机会“想法不同”
“如果要让 Windows 有任何希望，其产品策略师不仅要为平台带来新功能，还必须从根本上重新设计体验，” Forrester 报告中的分析师 J.P. Gownder 和 Sarah Rotman Epps 说道。
许多当前的平板电脑都只是 iPad 的剽窃品。
它们基本上有相同的用户界面（具有相同大小的主屏幕图标的多个页面），它们使用的触摸手势几乎相同，它们看起来也基本相同。
但是，微软迟至如此之后才加入现代平板电脑的狂欢，这也给微软提供了一个很好的机会，来看看还有哪些地方没有做到，哪些地方可以做得更好，哪些地方可以做得不一样。
所有这些观察都可以为 Windows 8 平板电脑提供更好的参考。
比如说 Windows 8 的功能，它可以从平板电脑的用户界面切换到桌面用户界面，这可能是一个赢家的创新。
“我们正在到达一个点，ARM 平台可以为我们提供移动设备上的桌面体验，” Kelly Sommers 告诉 Wired.com。
如果这是真的，如果 Windows 8 平板电脑在桌面模式下能够克服 Windows 7 平板电脑所面临的性能问题，那么微软可能会以一个价格提供两种操作环境，从而大获全胜。
“我认为，理想的用户体验可以同时支持 [桌面用户接口和触摸式用户接口]，但不能同时使用，”萨默斯告诉 Wired.com。
“如果您把平板电脑停靠在监视器上，并且它变成了一个具有键盘和鼠标的桌面体验，用于非电源使用，您会怎么样？
把平板电脑脱离连接，它就会转变为平板电脑体验。”
事实上，谁不想要一款双操作系统的设备，可以既用作休闲平板，又可以用作无拘无束的生产力计算机呢？苹果和 Android 团队都没有解决这个非常现实的消费者问题。
Windows Phone Mango 表明微软在移动领域可以做得很好 微软进入移动领域的开端并不顺利，但最终在 Windows Phone 7（特别是 Windows Phone 7.5 Mango 版本）上找到了脚步。
虽然消费者并没有像 iOS 或 Android 那样涌向 Windows 的新移动操作系统，但如果你还没有试用过，你应该去试一试，它做的很好。
要亲眼目睹一下，请在您的移动浏览器中打开 http://aka.ms/wpdemo，试一试。
Display Search 分析师 Richard Shim 表示：“我认为微软在 Windows Phone 上学到的东西将会带到 Windows 8 上，并对其产生影响。”
微软正在努力与开发者联系，并通过 BizSpark 和 Mobile Acceleration Week 等计划提供支持、营销指导和应用程序可见度，以填补其仍然不足的应用程序产品线。
这些程序都取得了巨大的成功，因此我们可以预计微软将会继续在 Windows 8 中使用这些程序。
的确，如果 Windows 8 的执行如 Windows Phone Mango 那样出色，对用户来说将是一个积极的体验。
这是大多数 Android 平板电脑都无法做到的。
这也是微软的一大优势：Windows Phone 平台可能没有丰富的应用程序，甚至没有很多用户，但实际使用 Windows Phone 的人都能体验到基本的操作系统体验。
因此，如果 Windows 8 平板电脑能够在具有发言权的领袖人物中找到一块脚手架，那么消费者的采用就会自我延续，因为用户会代表微软宣传这些平板电脑。
